## Make your first contribution

1. Pick an issue labelled [good first issue](https://github.com/OWNER/NAME/issues?q=is%3Aissue+is%3Aopen+label%3A%22good+first+issue%22).
2. Comment `/take` on it: it's assigned to you, and you can start.
3. Follow [CONTRIBUTING.md](CONTRIBUTING.md) to set up, test and open a pull request.
4. We reply to newcomers' pull requests within 7 days. A review or a merge may take longer.

You can help without writing code, too: docs, translation, testing, design and accessibility. <!-- Keep only what this project accepts. -->
